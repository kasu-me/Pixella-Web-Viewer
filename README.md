# Pixella Web Viewer

[Pixella](https://github.com/kasu-me/Pixella) からエクスポートした JSON ファイルをもとに、画像の検索・閲覧ができる Web アプリです。

## 動作環境

- PHP 7.4 以上（静的ファイル配信 + `file_get_contents` が使用可能なこと）
- GD 拡張（`thumbnail.php` によるサムネイルのオンデマンド生成に使用）

## ディレクトリ構成

サーバーに以下の構成で配置してください。

```
webroot/
├── index.php            ← このファイル
├── config.php           ← パス設定
├── thumbnail.php        ← サムネイルのオンデマンド生成
├── favicon.ico
├── data/
│   └── pixella_export.json   ← Pixella からエクスポートした JSON
├── images/
│   ├── photo001.jpg
│   ├── photo002.png
│   └── ...              ← 全画像をファイル名のみで平置き
└── thumbnails/           ← サムネイルキャッシュ（自動生成。書き込み権限が必要）
```

## セットアップ手順

### 1. Pixella で JSON をエクスポート

Pixella アプリを起動し、メニュー「データを JSON 書き出し…」から
`pixella_export.json` をエクスポートしてください。

### 2. ファイルの配置

1. `pixella_export.json` を `data/` フォルダに配置する
2. JSON 内に登録されている画像ファイルを、すべて `images/` フォルダに**ファイル名のみで**配置する
   - サブフォルダ不可。ファイル名が重複する場合は注意してください

> **ヒント:** JSON の `images[].path` フィールドに元の絶対パスが記録されています。
> スクリプト等で一括コピーする際の参考にしてください。

### 3. 動作確認

ブラウザで `index.php` にアクセスすると画像一覧が表示されます。

## 機能

| 機能 | 説明 |
|---|---|
| タグ検索 (AND) | 選択した全タグを持つ画像のみ表示 |
| タグ検索 (OR)  | 選択したいずれかのタグを持つ画像を表示 |
| タグフィルタ入力 | 利用可能タグを文字でしぼり込み |
| グループ表示 | グループタイルをクリックするとグループ内の画像を表示。パンくずでホームに戻る |
| 並び替え | 更新時刻 / 追加時刻 / ファイル名で昇順・降順切り替え |
| レーティング絞り込み | 星の数を指定し ≧ / = / ≦ で比較（画像・グループ両方が対象） |
| テーマ切り替え | ライト / ダークモード。OS 設定に連動し、手動トグルの結果は localStorage に保存 |
| サムネイル自動生成 | `thumbnail.php` が長辺 150px のサムネイルをオンデマンド生成・キャッシュ |
| ページング | 100 枚 / ページ。URL パラメータ `?page=2` 対応 |
| ライトボックス | 画像クリックでフルサイズ表示。左右キー / ボタンで前後移動 |
| URL 共有 | タグ・モード・ページ等をすべて URL パラメータに保存するため、URL 共有可能 |

## URL パラメータ

| パラメータ | 例 | 説明 |
|---|---|---|
| `tags` | `?tags=風景,旅行` | カンマ区切りのタグ名 |
| `mode` | `?mode=or` | `and`（デフォルト）または `or` |
| `page` | `?page=3` | ページ番号 |
| `group` | `?group=12` | グループ ID。指定するとそのグループ内の画像一覧を表示 |
| `sort` | `?sort=filename` | `mtime`（デフォルト） / `ctime` / `filename` |
| `sortdir` | `?sortdir=asc` | `asc` または `desc`（デフォルト） |
| `rfilter` | `?rfilter=1` | レーティング絞り込みを有効化（`1` で有効） |
| `rop` | `?rop=eq` | レーティング比較演算子: `gte`（デフォルト） / `eq` / `lte` |
| `rval` | `?rval=3` | レーティングの星数（0〜5） |
| `imgid` | `?imgid=42` | ライトボックスで開く対象の画像 ID |

## config.php の設定項目

| 定数 | 説明 |
|---|---|
| `PIXELLA_TITLE_SUFFIX` | ページタイトルに付与するサフィックス |
| `FAVICON_FILE` | favicon ファイルの場所（`config.php` からの相対パス） |
| `DATA_FILE` | JSON エクスポートファイルの場所 |
| `IMAGES_DIR` | URL 上の画像ディレクトリ（末尾スラッシュ必須） |
| `IMAGES_FS_DIR` | ファイルシステム上の画像ディレクトリ（`filemtime` 取得用） |
| `THUMBNAILS_FS_DIR` | ファイルシステム上のサムネイルディレクトリ |
| `GROUP_SORT_DEFAULT` | グループ内画像のデフォルトソート順（`same` / `mtime_asc` / `mtime_desc` / `ctime_asc` / `ctime_desc` / `filename_asc` / `filename_desc`） |

## タイトル表示のカスタマイズ（任意フック）

`index.php` はライトボックスやグループ見出しのタイトルを表示する際、`title_provider.php?id=<ファイル名>` を fetch してタイトル用の HTML を取得しようとします。このファイルは同梱されておらず、存在しない場合（404 応答）は無視されて何も表示されません。タイトルをカスタマイズしたい場合にのみ、任意で `title_provider.php` を自作して配置してください。

## 注意事項

- 画像ファイルは `images/` に**ファイル名が重複しない**ように配置してください
- JSON ファイルを更新した場合は、ページをリロードすれば反映されます
- 画像数が非常に多い場合（数万枚規模）は、JSON ファイルのダウンロード量が増えます。
  その場合は `PER_PAGE` 定数の調整よりも、PHP 側でページングする方式への変更を検討してください
